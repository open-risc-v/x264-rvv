## 为什么基线要 `--disable-asm`

x264 的 aarch64 NEON 与 riscv 汇编走的是不同实现，码流必然不同字节。基线阶段先证明
"同一份纯 C 上游在 riscv 上能编、能跑、码流一致"，汇编/RVV 的差异留给 G3 用差分框架判。
